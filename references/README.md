# Acuan proyek SUVIFOR UNNES

Sumber asli dari pengguna disimpan utuh di `stitch-original.txt`. File ini memuat tiga dokumen HTML: design system, navigation overlay, dan halaman utama UAV Research Team. Baca bagian terkait sebelum mengimplementasikan kartu kanban; jangan menganggap gabungan ini sebagai satu dokumen HTML siap jalan.

## Kesepakatan pengerjaan

- Kerjakan website bertahap mengikuti kartu to-do kanban yang dikirim pengguna.
- Tunggu kartu pertama sebelum memulai implementasi website.
- Ikuti tampilan dan konten copy Stitch sebagai acuan, termasuk layout, warna, tipografi, komponen, dan interaksi.
- Pertahankan sumber asli ini untuk referensi pada tahap berikutnya.
- Ada perbedaan token antara design system dan halaman utama; gunakan dokumen yang sesuai dengan bagian yang sedang dikerjakan, jangan menyeragamkan secara sepihak.

## Isi referensi

- Design system: Aerospace Brutalism, gold #FFA800, carbon #111215, ochre #DEA810, neutral #EAE6DF; Syne, Plus Jakarta Sans, JetBrains Mono.
- Navigation overlay: referensi menu navigasi.
- Halaman utama: hero, about us, work programs, recruitment dan agenda, contact, footer; menggunakan Syne, Space Grotesk, JetBrains Mono dengan aksen #FACA42 dan latar #1D1819.
