# SUVIFOR UNNES — Acuan desain

Dokumen ini dirangkum dari copy Stitch pengguna. Sumber lengkap dan asli: [references/stitch-original.txt](references/stitch-original.txt). Sumber berisi tiga dokumen HTML terpisah; jangan dijalankan sebagai satu halaman.

## Aturan implementasi

- Kerjakan bertahap sesuai kartu kanban pengguna.
- Ikuti struktur, copy, warna, tipografi, gambar, dan interaksi dari dokumen Stitch untuk bagian yang dikerjakan.
- Halaman sementara pada setup bukan implementasi final landing page.
- Token board dan halaman utama berbeda. Gunakan token halaman utama untuk website; pertahankan board sebagai referensi terpisah.

## Halaman utama dan navigasi

Gaya aerospace brutalism: sudut tegas, garis pembatas, heading besar, label monospace, aksen kuning dengan latar gelap.

| Token | Nilai |
| --- | --- |
| Latar | #1D1819 |
| Aksen | #FACA42 |
| Teks utama | #FEFEFE |
| Teks sekunder | #CCC5B2 |
| Border | #373335 |
| Heading | Syne |
| Body | Space Grotesk |
| Label | JetBrains Mono |

Urutan halaman: header dan hero, about us, work programs, recruitment dan agenda, contact dan CTA, footer. Navigasi mengacu pada overlay curtain slide-down dengan tombol buka/tutup, tautan bagian, dan dukungan Escape. Implementasinya mengikuti kartu berikutnya.

## Design system board

Gold #FFA800, carbon #111215, ochre #DEA810, surface #EAE6DF, card #F3F0EA, border #DDD8CE. Font: Syne, Plus Jakarta Sans, JetBrains Mono. Board berisi contoh warna, tipografi, tombol, input, badge, dan navigasi.

## Aset dan konten

URL gambar dan teks asli tetap tersimpan di sumber Stitch. Periksa tujuan tautan formulir, kontak, serta agenda sebelum publikasi. Simpan aset lokal baru di src/assets atau public sesuai kebutuhan kartu.
